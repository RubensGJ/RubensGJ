## Projetos em destaque

### AgroSmartAPI

API auxiliar do projeto AgroSmart, desenvolvida para coletar, salvar e consultar cotações agrícolas.

**Principais pontos técnicos:**

- API REST com **Node.js** e **Express**
- Coleta automatizada de cotações com **Puppeteer**
- Persistência de dados com **PostgreSQL/Neon**
- Histórico de cotações e cache em memória
- Rotinas automáticas com **node-cron**
- Documentação com **Swagger/OpenAPI**
- Deploy em ambiente cloud

**Stack:** Node.js, Express, Puppeteer, PostgreSQL, Neon, Swagger/OpenAPI

**Links:**

- Repositório: [github.com/RubensGJ/AgroSmartAPI](https://github.com/RubensGJ/AgroSmartAPI)
- Documentação/Deploy: [agrosmartapi.onrender.com/docs](https://agrosmartapi.onrender.com/docs)

**Minha atuação:**
